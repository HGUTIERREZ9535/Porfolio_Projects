# COVID-19 Data Exploration Using SQL

## Overview

In this project, I used **SQL Server** to explore COVID-19 data and analyze cases, deaths, population, and vaccinations across different countries and continents.

The goal was to practice SQL skills while turning raw data into meaningful information that could later be used for visualization and further analysis.

## Tools

* SQL Server
* SQL
* SSMS
* GitHub

## What I Analyzed

* Total COVID-19 cases and deaths
* Death percentage compared to reported cases
* Reported cases compared to population
* Countries with the highest reported cases and deaths
* Global cases and deaths over time
* Vaccinations compared with population
* Rolling vaccination totals

## SQL Skills Used

This project allowed me to practice:

* `SELECT`, `WHERE`, and `ORDER BY`
* `GROUP BY` and aggregate functions
* `JOIN`
* `CAST`
* `CASE`
* Window functions
* `PARTITION BY`
* Common Table Expressions (CTEs)
* SQL Views

## Key Learning

One of the main concepts I learned was how to use **window functions** to calculate rolling vaccination totals by location and date.

I also learned how to combine multiple datasets using `JOIN` and organize more complex calculations using **CTEs**.
